# lab-repo
# Лабораторные работы по дисциплине «Технологии и методы программирования»

Репозиторий содержит лабораторные работы по программированию на языке Python.

Вариант: **1**  
Объект: **Доходы**  
Свойства объекта:

- дата;
- источник дохода;
- сумма.

## Структура репозитория

```text
lab-repo/
├── lab_01/
├── lab_02/
├── lab_03/
├── lab_04/
├── .gitignore
└── README.md
```

Каждая лабораторная работа расположена в отдельной папке.

## Лабораторная работа 1

В первой лабораторной работе реализована программа, которая формирует программный объект на основании текстовой строки.

Пример входной строки:

```text
Доходы 2024.03.28 "Зарплата" 50000
```

Программа разбирает строку на отдельные части, преобразует дату и сумму к нужным типам данных, создаёт объект `Income` и выводит его свойства на экран.

Папка работы:

```text
lab_01/
└── main.py
```

## Лабораторная работа 4

В четвёртой лабораторной работе добавлена обработка файла команд.

Поддерживаются команды:

```text
ADD <данные>
REM <условие>
SAVE <filename>
```

Команда `ADD` добавляет новый объект дохода.  
Команда `REM` удаляет объекты, соответствующие условию.  
Команда `SAVE` сохраняет текущее состояние данных в файл.

Также были добавлены модульные тесты для обработчика команд и выполнена оценка покрытия кода тестами.

Покрытие тестами составило:

```text

```

## Запуск программ

Для запуска нужной лабораторной работы необходимо открыть соответствующую папку и запустить файл `main.py`.

Например:

```bash
python lab_01/main.py
```

или:

```bash
python lab_04/main.py
```

## Запуск тестов

Для запуска тестов третьей лабораторной работы:

```bash
python -m unittest discover -s lab_03
```

Для запуска тестов четвёртой лабораторной работы:

```bash
python -m unittest discover -s lab_04
```
